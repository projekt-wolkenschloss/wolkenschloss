# Developer Documentation

## Release Process

To release a version, just use the release UI in Forgejo.

## Development Setup

To develop Wolkenschloss, we recommend to use Linux, especially NixOS (surprise). Other setups are not supported by us.

First, you need a working install of `nix` and `direnv`.
After checkout, allow direnv on this folder with `direnv allow .`.
That should be it.
